# 🚀 Enterprise DevOps Platform for Java Three-Tier Application

Built a production-style DevOps platform featuring automated CI/CD, Infrastructure as Code, code quality analysis, artifact versioning, containerization, cloud deployment, load balancing, monitoring, and scalable Azure infrastructure.

# 📌 Project Overview
This project demonstrates an enterprise-grade DevOps CI/CD pipeline for deploying a Java three-tier web application on Microsoft Azure. The infrastructure is provisioned using Terraform, while Jenkins automates the build, testing, code quality analysis with SonarQube, artifact management using Nexus, and containerization with Docker. The application is deployed behind an Azure Load Balancer with Nginx as a reverse proxy, and the environment is monitored using Azure Monitor and Log Analytics. The project also implements a remote Terraform backend in Azure Storage for secure state management and follows Infrastructure as Code (IaC), Continuous Integration (CI), and Continuous Deployment (CD) best practices. It is designed to reflect a real-world enterprise DevOps workflow with automation, security, scalability, and monitoring.
